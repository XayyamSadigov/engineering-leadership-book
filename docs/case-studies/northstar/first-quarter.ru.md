# Northstar: первый год директора { #northstar-the-directors-first-year }

!!! warning "Вымысел"
    Всё на этой странице придумано для книги. См. примечание в
    [обзоре Northstar](index.md).

Эта страница — летопись первого года директора по разработке в Northstar в хронологическом порядке:
решения, которые действуют до конца книги, первый квартал по неделям, итоги дня 90, а затем кварталы 2,
3 и 4. В каждой строке указана глава, которая рассказывает эту часть истории, чтобы главы не
противоречили друг другу.

Недели отсчитываются от первого дня директора. Каждый квартал директора длится 13 недель: квартал 1 —
недели 1–13, квартал 2 — недели 14–26, квартал 3 — недели 27–39, квартал 4 — недели 40–52. Стартовое
состояние — на странице [исходных данных](baseline-data.md), люди — на странице
[«Действующие лица»](cast.md). Обзор на одной странице — [хронология](timeline.md); читатели, которые
начинают с частей X–XIII, могут начать с [брифинга по итогам четвёртого квартала](quarter-4-briefing.md).

Таблицы на этой странице повторяют английскую версию: числа в них записаны так же, как в английском
издании.

Определение роли директора (глава 1):

- **Назначение:** надёжность и поставка всей организации.
- **Люди:** развивать шестерых руководителей; дать staff-инженерам мандаты.
- **Поставка:** владеть межкомандными обязательствами и моделью ресурсов.
- **Техника:** следить, чтобы у межкомандных решений был владелец.
- **Чего не делать:** вести планирование команды, реагировать на инциденты, писать продакшен-код.

Ограничение «без роста численности» считает всю инженерную организацию (87 человек). Повысить
инженера на новую роль руководителя можно, только если его инженерное место не будет заполнено заново.
