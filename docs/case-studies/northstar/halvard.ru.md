# Halvard Systems: компания для сравнения { #halvard-systems-the-comparison-company }

Halvard Systems — вторая вымышленная компания книги. Она используется там, где Northstar слишком мала,
чтобы показать проблему: в организациях из нескольких сотен инженеров, с несколькими вице-президентами и
уровнем высшего руководства над ними. Как и Northstar, она придумана, и каждое число на этой странице —
учебное допущение, а не бенчмарк. Люди перечислены на странице [«Действующие лица»](cast.md).

## Форма { #shape }

## Год после года планирования { #the-year-after-the-planning-year }

Главы 56–59 рассказывают четыре истории, которые происходят после описанного выше года планирования,
каждая внутри одной группы: Payroll (глава 56), Commerce (глава 57), Field Operations и Insights
(глава 58) и платформенная организация с корпоративными политиками (глава 59). Стартовый размер каждой
группы — тот, что в таблицах выше. В отличие от четвёртого квартала Northstar, у этих историй итоги
записаны. Общая численность компании после этих событий не указана.
